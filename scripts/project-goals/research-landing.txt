Plain HTML with inline CSS, black text on white with one orange accent (#f26b1d), no JavaScript needed. Run node build.mjs and then verify with node -e that index.html exists, contains at least 24 rows with href links, and that JSON parses. Commit with git after each finished category and at the end.
