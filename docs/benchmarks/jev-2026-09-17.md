# Jev Hybrid comparison — 2026-09-17

All 80 attempts passed the independent fixture check (40 per engine). This run does **not** establish a general speed advantage: the median of all 40 paired Classic/Hybrid ratios was **1.01×**. Total task time was 661.13 s for Classic and 644.55 s for Hybrid. Search and form task medians improved, while autocomplete and scrolling did not. There are only five repetitions per scenario and substantial primary-model latency variation; there is no evidence here for a general 2× claim.

Hybrid used zero Jev decisions in **28/40** attempts. The current integration lets the primary planner choose ordinary tools, so this measures the shipped Hybrid workflow, including that routing behavior. It does not isolate Jev's contribution. The median of the 39 actual Jev decision latencies was 290 ms. A future routing experiment would need its own frozen run and the same success checks.

This is Classic versus Hybrid on the experimental branch, with `gpt-5.6-sol` at low effort in both modes and pinned `jev-1.13.0`. It is not a comparison against unmodified main. Each attempt had a fresh browser profile and the same viewport; order alternated, and browser egress was limited to the local fixture server. Podman/Electron startup is excluded. These synthetic tasks do not establish general website reliability.
