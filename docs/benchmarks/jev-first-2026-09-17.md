# Jev First: measured comparison, 2026-09-17

The tested recommendation is **Jev First with Luna / low**. In the final same-model comparison, First passed **24/24** independent checks with a **15.12-second median**, versus Classic at **23/24** and **24.93 seconds** among successful attempts. The median paired speed ratio was **1.48×**. This is evidence from eight small local scenarios, not a universal web speed claim.

## Interpretation and limits

The original optional Hybrid frequently did not use Jev. First delegates browser outcomes before ordinary mutations become available, returns fresh evidence to the selected primary model, and retains controlled fallback for uncertain or unsupported interactions. The main latency cost remains the primary model. The final correction path also returns fresh evidence after each fallback action to avoid a separate observation round trip.

These are small local fixtures, not a general web-agent reliability benchmark. The protocol and security checks, field values, browser, viewport, egress restriction and external success check are shared across each comparison. Each fixture is validated deterministically before model calls. All failures are retained. Confidence is a heuristic threshold; DONE is always unverified until the primary model checks separately captured evidence.

Earlier [pilot](jev-first-pilot-2026-09-17.json), [redundant-read diagnostic](jev-first-diagnostic-2026-09-17.json) and [provider-error diagnostic](jev-first-service-errors-2026-09-17.json) are preserved separately. The two intentionally interrupted attempts in diagnostic series are not mixed into the completed comparison. Direct probes observed HTTP 503; the [provider status page](https://status.typesafe.ai/) reported operational service, so these measurements do not establish a provider-wide outage.


## Validation

The final source passed typecheck, build and **421 tests** (12 skipped). New regression coverage includes initial navigation policy, gated fallback, fresh evidence after corrections, no replay after failed mutations, Stop during inference/backoff, takeover, budget pause, delayed approval, bounded overload retries and sanitized provider diagnostics. Classic and the original optional Hybrid remain selectable.

The final Electron → daemon → browser-container check passed with Luna/low: it reached the independently checked IANA URL/title in 11.62 seconds including UI submission, stopped a subsequent task in **19 ms**, and then completed a Classic task without Jev statistics. There were no renderer errors. [Final desktop check](jev-first-desktop-final-2026-09-17.json). The test left the experimental instance configured for Jev First and Luna/low, without starting another task.
